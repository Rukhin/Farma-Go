🔐 VALIDASI YANG DIIMPLEMENTASIKAN

FIELD REQUIRED (Harus Diisi):
  • Kode Obat *
  • Nama Obat *
  • Kategori *
  • Unit/Satuan *
  • Harga Beli *
  • Harga Jual *
  • Stok Awal *
  • Stok Minimum *

UNIQUE VALIDATION:
  • Kode Obat (tidak boleh duplikat)

PRICE VALIDATION:
  • Harga Jual >= Harga Beli

NUMERIC VALIDATION:
  • Harga harus angka
  • Stok harus angka bulat

PROTECTION:
  • Tidak bisa hapus jika ada transaksi

🗂️ DATABASE STRUKTUR

Table: medicines
  • id (PK)
  • code (String, Unique) - Kode obat
  • name (String) - Nama obat
  • medicine_category_id (FK) - Kategori
  • unit (String) - Unit/Satuan
  • price_purchase (Decimal) - Harga beli
  • price_sale (Decimal) - Harga jual
  • stock (Integer) - Stok saat ini
  • min_stock (Integer) - Stok minimum
  • description (Text, Nullable) - Deskripsi
  • created_at (Timestamp)
  • updated_at (Timestamp)

🆘 TROUBLESHOOTING

ERROR: "Kode obat sudah terdaftar"
SOLUSI: Gunakan kode yang belum pernah dipakai

ERROR: "Harga jual harus lebih besar dari harga beli"
SOLUSI: Pastikan harga jual >= harga beli

ERROR: "Obat tidak dapat dihapus karena sudah terlibat dalam transaksi"
SOLUSI: Obat hanya bisa dihapus jika belum ada pembelian/penjualan

ERROR: "Kategori obat tidak valid"
SOLUSI: Pilih kategori dari dropdown yang tersedia
